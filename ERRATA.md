# Errata

Corrections to the printed text of *Grace: The Value of Choice*. The
copyright page of a copy says which revision it was printed from.

## First printing (revision 91b6f16, 2026-10-03)

**Page 117, 7.5 Trial — the tide table.** The value-iteration exercise has no finite-horizon extension: the sentence promised one.

- was: the finite-horizon backup is a half-hour addition to The exercise for this chapter and is set as the extension exercise there.
- now: the finite-horizon backup is a half-hour addition to the value-iteration code from Chapter 5.

**Page 212, 13.7 Trial — build it.** The exercise is shared by Chapters 12 and 13; the sentence read as if it were not.

- was: Part A of The exercise for this chapter built the linear machinery of Chapter 12.
- now: Part A of this exercise built the linear machinery of Chapter 12.

**Page 251, 16.8 Trial — build it.** The sentence did not say which exercise.

- was: The closest thing already built is the exercise,
- now: The closest thing already built is the bandit exercise of Chapter 2,

**Page 334, 22.7 Trial — build it.** The sentence did not say which exercise.

- was: Take the estimator of the exercise,
- now: Take the estimator built for Chapter 21,
